# Blender Tools

Custom Blender add-ons and helper scripts for animation, rigging, retargeting, and workflow automation.

## Tools

- **[Fist Pose Cleaner](../fist-pose-cleaner/README.md)** — replaces finger animation in the active action with a static closed-fist pose for Auto-Rig Pro rigs. Install and enable it in Blender, then use the Animation sidebar panel. See the separate guide for installation, usage, and limitations.
